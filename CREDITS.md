# Credits

Ìtàn: Moonlight Tales uses these third-party assets. Most are not stored in this
repository: run **Itan > Assets > Download Third-Party Assets** in Unity to fetch
them (the full list with URLs is in `Assets/_Project/ThirdPartyAssets.txt`).

The narrator's voice is generated with Kokoro TTS (kokoro-onnx, Apache 2.0, voice
"bm_george") from the script exported by **Itan > Narrator > Export Narration Script**. Sound effects and ambience are made for the project (CC0).
